# Legacy UI Evidence Archive

Status: stale historical reference only

Archived on: 2026-07-18

The `rc34-*` and `rc35-*` screenshots and UI hierarchy dumps predate the
Feishu-source-driven Android rebuild. They do not represent the current LaoJi
implementation and must not be used as current parity, review, or acceptance
evidence.

These files are retained only to explain previously observed failures. New UI
work must use the current source tree and the Feishu Android 7.71.8 source
baseline. Do not move these artifacts back into `test-assets/android-device`.

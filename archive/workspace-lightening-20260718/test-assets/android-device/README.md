# Current Android Device Artifacts

Only artifacts captured from the current worktree may be placed here.

Use the filename form:

`YYYYMMDD-<git-short-hash>-<route>-<state>.<png|xml>`

Every capture set must include the Git short hash in its filename. Artifacts
without a matching current commit or worktree snapshot are stale and belong in
`archive/legacy-ui-evidence`, not in this directory.

The old `rc34` and `rc35` captures were moved to
`archive/legacy-ui-evidence/rc34-rc35` on 2026-07-18.

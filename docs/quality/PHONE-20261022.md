## 本轮发现及修复

1. 问题正文在数据库/无障碍树中完整，纸境实显却裁掉英文末尾。Android Activity 继承主题字体，而 RN Text 未显式指定同一字体，导致测量与实际绘制的字宽不同。问答 owner 的文本与输入显式使用现有主题字体；不以增高、缩字、裁剪或换字体掩盖。纸境模拟器同一英文问题修复后完整显示；四主题组件合同均校验测量字体。
2. 待办编辑页删除先退出编辑窗口，但集合窗口仍为 RN Modal，挡住了 native 页面的确认对话框。修复为先释放两个窗口，再显示唯一确认；取消恢复原编辑上下文，提交后回到集合，离开会议不弹出迟到确认。保留既有删除确认，不改用无确认永久删除或直接改 SQLite。

首次问答 UI 探针误判超时：Android 将 turn 子节点扁平化成同级，探针只遍历 XML 子树而漏检已完成答案。已按可见 turn 边界归属修正；同时区分点击未发出、探针未能确认和真实服务失败。探针错误不计为产品请求失败，也不倒填虚假的完成耗时。模拟器一次发送点击被键盘布局变化影响，草稿未发出，重试后真实完成；不计作成功请求样本。

## 覆盖遗漏发生在哪

使用现有真实 Android ASR：长会议 225 条转写，短会议及当前笔记。没有用字幕替代 ASR，评测正文只保存在本机 `output/summary-coverage-20261022/`。

- 长会议被无损规范打包为 31 个来源，全部进入输入，未触发 embedding 选段。估计输入 4,947 tokens；真实 Android 调用的 Ollama `prompt_eval_count=5412`、`eval_count=614`，正常结束，仍为既有 16,384 context。末尾价格事实也实际出现在模型输出，不能把这次遗漏归因于上传截断、模型没收到后半段或输出超限。
- 模型正常一次生成了 12 条事实，其中大量是公司、产品和接待背景；付款比例、尾款期限没有生成。12 条均被标为 context。校验后剩 11 条，其中成立年份那条未通过原来的数字／单位字面约束；不能把这一条的删除当成整个后半段遗漏的原因。
- 真实 Android 服务返回的 11 条事实，投影为“概述”和含 11 项的“主题与要点”。并非手机只显示了前两项或把其他事实丢掉；当前输入的事实类型单一，富内容协议也不能凭空生成结论或关系。
- `source_coverage=1`、`topic_coverage=1` 在此只证明输入纳入情况，不是语义总结覆盖率。HTTP、Schema、Task 成功都不等于整理质量合格。

短会议同样存在重复背景、主体／数字解释不够可靠；不能用短会议请求成功否定长会议的真实遗漏。

## 两个未采用的候选

1. **共享问答数值归一化。** 能处理部分中文／阿拉伯数字差异，但只比较数值集合会让不同单位也通过：真实执行反例中 `24人` 对 `24元` 返回支持。长／短会议各一次真实生成也没有解决核心遗漏。因此候选、共享模块和专属测试全部撤回；问答 reader 恢复原 SHA-256 `b197aae415f108d98794591991bacee703f4029d13725c00f512fc105f31a79c`。不以“兼容中文数字”为由降低事实约束。
2. **按来源顺序预留事实槽位。** 一次调用内将来源按 token 量分为四组，各最多三个槽位；首引用受对应来源组约束，不增加模型、上下文、总事实数或 Map/Reduce。三项隔离合同通过，长／短会议各一次真实生成。能增加后半段内容，但长会议错把中间预付方案作为最终条件，且把付款条件当作待执行行动；短会议仍有重复。整版未采用，临时实现与专属测试已删除，不留备用开关。

两组正常基线、两组数值候选、两组槽位候选及两组最终 token 校验回放共 **8 次独立真实生成**，不是 8 个独立会议；另有 1 次 Android 生产链调用。私有候选最初因 prompt 文件相对路径错误在模型调用前失败，已修正诊断器的显式 prompt owner；不计作生产服务故障或质量样本。

## 实际采用：完整数值 token 保护

原整理校验把数字当作子串：较大值中的若干字符可以给较小值提供伪依据。已改为完整数字 token 比较，保持显式单位／日期后缀约束；小数尾零、全半角百分号和普通空白不制造不同数值。没有放宽单位、重新生成答案、补数值、修改引用、增加模型调用或加入样本词。

这仍是数字字面完整性检查，不负责中文口述数值转换、单位语义、建议／最终状态或完整事实蕴含，不能因此宣称语义质量提升已全部通过。

- 整理／章节合并／worker／问答／引用及新增数值回归 **156 项通过**；另有只读维护探针 **4 项通过**。这些不是 160 个人工语义样本。
- 两个真实输入的模型 raw、展开响应和最终事实文档，与修改前分别逐字／结构一致；未发现这片引入的新内容退步。纯调用计时长会议 8,677→8,738 ms、短会议 13,246→13,480 ms，无提速结论。
- 只原子替换生产 generator 与 runtime identity，handler 升为 `summary-facts-v3-chapter-r6`，避免旧任务/检查点身份被当作新校验版本继续使用。旧结果未重做或覆盖。generator SHA-256 `0a1b046b7c383d5724825655cfd441ab011c3d436495bb68bc1781e7808d1fc4`，runtime SHA-256 `1a700eacfef8ab328bf6f95a636ad4663993ea6a60b53b0c225a3195b2f25679`。
- 专用 5562 的实际 JS owner 经设备鉴权、来源流、Task、生产模型和本机解析／投影完成一次生成，23,723 ms；客户端收到 r6，31/31 来源、11 条事实、2 个板块。探针没有激活新整理版本，没有替换会议当前结果，原记录与历史保留。这不是原生页面画面或真机验收。

API 做过一次短重启，ASR／Ollama未重启，GPU1、PCB、Smart Meeting 和其他项目未动。重启初次模型预热 readiness 曾为 false，随后推理链恢复；不称零中断。

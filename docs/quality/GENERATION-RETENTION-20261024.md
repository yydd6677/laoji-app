# 生成结果保留设置修正

后续真机补验已完成：问号气泡关闭/触摸隔离、开关保存后重进、升级后保持原设置均通过，见 [调试恢复后的真机补验](PHONE-ACCEPTANCE-20261024.md)。以下保留 273 当时的历史验证边界。

## 产品合同

协作者询问含义，不意味着应删除其选择权。恢复“保留生成结果”，默认关闭；相邻问号打开说明气泡，不增加常驻说明，不点击开关、不挤动设置列表。气泡说明服务端质量改进用途、可能包含隐私、关闭的影响，不再承诺匿名。

这不是复活原本仅写 AsyncStorage 的空开关。当前设备/数据域的权限由经过 v2 鉴权的 GET/PUT `/api/device/v2/privacy/generated-results` 管理；手机只在服务端确认后反映结果。失败时不伪装成功，原位提供重试读取，不弹“知道了”。

## 服务边界

- 自愿质量副本与任务恢复结果分离。关闭会停止并清除当前设备/数据域的质量副本和授权，不删除本机会议、转写、整理、日程或恢复结果。
- 新任务创建时记录授权 revision；发布输出时再核对当前权限。撤销后重新开启不会补收旧任务，旧任务重放不能获得新授权。
- 文件导入存在独立 Task 创建入口，本轮已同时接入，不只覆盖普通任务入口。
- 导入与实时稳定文字、完整整理 artifact、问答输出从实际生成者进入同一加密副本 owner；不保存原音频、笔记输入或请求正文。生成结果自身仍可能包含姓名或来源摘录，因此不称匿名。
- 副本以 AES-256-GCM 加密，关闭、会议永久删除、数据域清除具有对应删除边界。可选副本失败使用事务保存点回滚自身，不降级或回滚用户的正常任务结果。
- 生产采用基于实际运行源码的八文件最小增量，保留线上既有能力门与配置。没有部署本地工作区的其他历史清理或功能变更。

# 历史归档说明

历史工作区、评测素材、真机证据和构建产物不随公开仓库发布。它们由项目维护者在独立的私有归档介质中按日期和 SHA-256 管理，归档位置、访问凭据和恢复授权不写入仓库。

## 归档内容类别

- 变更前的源码快照和 Git bundle；
- 已停止使用的设计、演示和评测资料；
- 旧 APK、AAB、mapping 和可再生构建缓存；
- 真实录音、截图、日志和设备证据；
- 私有部署审计、服务运行记录和会话修复备份。

## 恢复原则

恢复前先查看归档清单和校验和，再解压到新的临时目录。不要覆盖当前工作树、生产服务目录或协作者正在使用的分支。公开仓库只通过 Git 提交和标签恢复源码，不通过归档包恢复运行时密钥或用户数据。

## 当前仓库不保留的内容

开发机路径、服务器真实目录、访问令牌、签名私钥、用户会议数据、设备序列号和其他项目素材都不应出现在公共文档、提交信息或测试夹具中。需要引用外部证据时，使用仓库相对路径、提交哈希和脱敏的环境变量名。

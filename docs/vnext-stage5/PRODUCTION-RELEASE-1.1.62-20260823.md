# vNext Android 发布记录：1.1.62（170）

## 结果

- 发布状态：已开放在线更新并覆盖安装到当前真机。
- Android：`1.1.62`，`versionCode=170`，包名 `com.laoji.app`。
- 本次仅发布客户端；生产 API、ASR、Ollama 和其他服务未重启。
- 旧 APK 和旧版本清单继续保留。

## 修复内容

- 修复 `1.1.61` 误嵌开发配置、设备引导密钥为空且 vNext 上传能力关闭的问题。
- 设备凭据恢复后，本机已有待上传资产沿原队列自动转入 device-v2/R2 链路，不要求重新选取文件。
- 视频源文件不再与音频上传上限直接比较；只对原始音频或视频抽取后的音频结果执行上传体积校验。
- 视频准备阶段不再按整个视频文件体积预留第二份空间，避免大视频在抽音前被错误拒绝。
- Release 构建新增生产配置与更新签名双门禁，防止开发配置或不兼容签名再次成为可发布 APK。

## 真机证据

- 覆盖安装后版本为 `1.1.62 (170)`，本机数据未清除。
- device-v1 capabilities 从 `401 DEVICE_CREDENTIAL_INVALID` 恢复为 `200`。
- device-v2 capabilities 返回上传、导入转写、实时转写、日程图、来源流和问答能力全部可用。
- 原有待上传队列从 9 条依次下降到 8、7、6、5、4 条；观察窗口内 `failed=0`。
- 生产 ASR 持续收到 `media.upload` 批次并成功推理，服务仍为 ready。

## 大视频边界

用户报告的 `829384557-1-208.mp4` 实际大小为 `1,528,009,077` bytes，音轨为 AAC，
约 72 分钟、192 kbps；音频包合计 `103,771,472` bytes。旧版在抽音前按 1 GiB 的
音频服务上限比较原视频，因而误拒绝；新版会放行视频源，并在抽取过程中校验约 99 MiB
的实际音频结果。当前仍保留服务端 1 GiB 单音频资产安全上限和本机可用空间保护。

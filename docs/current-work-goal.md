# 当前工作目标：飞书日历重构与发布质量

更新日期：2026-07-15

## 目标

把老记 Android 移动端完善为可发布候选版。日历结构、通用组件和动效以飞书 Android 7.71.8 源码为基线，删除老记无法提供或明确不需要的协作能力；语音创建、会议录制、转写和总结保持老记自己的产品路径。

详细产品例外与审阅规则见 `docs/feishu-calendar-baseline-contract.md`，语音入口见 `docs/voice-schedule-interaction-contract.md`。本文件是现阶段实施顺序和完成条件的权威清单。

## 已建立的基线

- 只保留月视图和单日视图，视图按钮直接切换，一周从周日开始。
- 月视图已具备连续跨日条、固定槽位、相邻月预取和源码对齐的基本几何。
- 日视图已具备 25 个小时标签、48 个半小时创建区、全天区域和跨午夜创建。
- 搜索、详情、编辑、年月选择和底部导航已迁入新的飞书化页面结构。
- 日程加号短按打开创建方式面板，长按可沿四分之一圆弧拖选语音或手动创建。
- 语音页支持短按持续录音和按住松开结束，并保护异步解析退出状态。

## P0：先保证数据正确和版本可交付

1. 为重复事件建立稳定引用 `{ sourceEventId, occurrenceDate }`，统一搜索、详情、编辑、删除和提醒。
2. 将冲突检测下沉到事件仓库，按目标日期范围查询并展开相关重复实例，不依赖当前屏幕缓存。
3. 将删除、撤销、提醒取消和失败回滚改成确定状态机；延迟 DELETE、失败 DELETE 和并发撤销后，服务端及本机都必须恰好保留预期的一条事件。
4. 增加通知响应导航和可恢复注册表；前台、后台、冷启动点击提醒都进入正确日程详情，不产生重复或残留提醒。
5. 所有运行源码、测试和公开合同必须进入版本控制，并从干净检出重跑完整门禁。

## P1：统一事件语义与恢复能力

1. 提取语音和手动创建共用的事件草稿校验器，覆盖非法日期、非法时分、单边时间、反向区间、跨午夜和重复规则。
2. 为缓存增加版本化 schema、损坏隔离和恢复提示；月份缓存改为有界缓存，加载与错误按范围隔离。
3. App 回到前台时去重刷新当前月、相邻月和搜索目录；离线继续显示缓存并保留可恢复错误。
4. 统一 `00:00` 结束边界，使月视图、日视图、搜索和日期筛选使用同一半开区间语义。
5. 修复按重复实例实际日期搜索、远期实例详情和编辑。
6. 时间编辑器的可见值、无障碍值和保存值保持一致，并覆盖短屏与横屏。

## P1：完成飞书日视图交互

1. 复杂重叠布局改为每个事件独立矩形、完整显示宽度和稳定绘制/命中顺序；无法从反编译源码恢复的布局算法使用真实 fixture 验证。
2. 支持单日定时事件的长按移动、上下边缘缩放、时间吸附、边缘自动滚动和保存失败回滚。
3. 左右换日、标题选日和异步刷新保持纵向位置、全天展开状态和内部滚动位置。
4. 收敛无障碍树，只暴露可见日期、事件和必要创建入口；使用 Android TalkBack 真机验收。

## P2：组件与动效收口

- 年月面板增加全屏透明触摸拦截，阻止点击穿透并支持点外收起。
- 详情头部增加速度/半高吸附和嵌套滚动消费。
- 搜索增加关键词高亮和稳定的按压覆盖反馈。
- 统一确认框、动作面板、底部覆盖层的圆角、遮罩和完整入退场。
- 清理固定坐标、旧文案和旧页面假设的 Android 验收脚本。

## 已确认裁剪

- 不实现多日历、日历账号、三日/列表视图和六入口底栏。
- 不复刻参与人、会议室、群聊、RSVP、签到和飞书会议联动；老记会议模块独立存在。
- 第一版事件统一主色，不做分类颜色。
- 登录账号当前不承诺离线写入队列；断网时必须明确失败或只读缓存，不能伪装已同步。

## 已确定产品决策

1. **语音保存路径**：保留语音确认页直接保存的快速路径，同时与手动创建共享同一校验器和事件仓库；“编辑更多内容”才进入完整编辑页，不为了代码复用强迫每次语音创建多跳一页。
2. **全天冲突语义**：全天事项与定时事项只显示软提示，不阻止保存；全天与全天、定时与定时按明确重叠规则提示。
3. **重复事件编辑范围**：实现“仅此日程、此后日程、全部日程”三种范围，再开放重复实例的拖动和删除。
4. **时区范围**：v1 按设备时区显示，数据模型先保留事件时区字段；独立时区选择器延后，不保留只有外观没有能力的入口。

## 完成门禁

- `npx tsc --noEmit --incremental false` 通过。
- Jest 全量通过，并补齐竞态、故障注入、复杂重叠和生命周期测试。
- `npm run audit:public` 与生产依赖审计通过。
- Android release APK/AAB 从干净克隆构建，不依赖 Metro 或 Expo Go。
- 真机验证通知回跳、语音两种录音方式、月/日切换、跨午夜、重复实例和 TalkBack。
- production 配置只使用 HTTPS/WSS 域名，不含裸 IP、明文流量、占位法律地址或测试签名。

## 修正的所有者

- 固件：`recording.list(include_previews=true)` 每页最多四个文件头预览；不扫描 PCM、不把预览写入完整 SHA 缓存。不携带扩展时保留原文件名列表合同。
- Android：目录 DTO `HardwareRecordingPreview` 与完整 `HardwareDeviceRecording` 分开。列表不调用 `recording.get`。选中文件才获取完整元数据，核对 generation 后才接收、改名或删除；接收仍执行完整 WAV/长度/PCM SHA 校验。
- 手机页：操作的 busy 生命周期不包含随后列表刷新；列表未返回时用局部加载态，不提前称“暂无录音”。目录结果以连接/阶段 fence 检查，不能覆盖正在录音的状态。
- 旧固件返回名字而无预览时，仅显示标题；不编造 0 时长、0 大小、虚构 generation 或“已接收”。

依据 product-engineering 的单一所有者/输入优先原则拆开浏览与完整性操作，依据 UI skill 保留控制几何并避免重复加载提示；没有用状态文案掩盖全量哈希延迟。

# 日程创建与语音输入交互合同

本文定义老记自己的高频日程创建体验。它不是飞书页面复刻清单：日历外壳继续参考飞书源码，语音内容与录音状态则按老记的任务流独立验收。

## 创建入口

- 右下角加号的短按行为保持稳定：打开底部“语音输入 / 手动新建”选择面板。
- 长按 350ms 后，以加号为圆心在左上四分之一圆弧显示“语音”和“手动”两个目标。
- 手指拖入目标并松开后直接进入对应流程；在目标之外松开只收起圆弧，不创建、不跳转。
- 长按手势不得在松开后继续触发短按行为。
- 圆弧只提供高频快捷方式，不取代可发现、可读屏的短按选择面板。

## 语音输入

- 页面标题使用“语音新建日程”，不使用宣传式或拟人式引导文案。
- 标题、左右操作区、输入框、错误槽和录音控制槽各自占有固定布局，不因错误、转写或连接状态改变主要控件位置。
- 关闭按钮位于独立的 72dp 侧栏；标题使用剩余空间，不以绝对定位覆盖操作区。
- 麦克风视觉圆直径 72dp，触控区 88dp；视觉尺寸不随录音状态改变。
- 短按一次开始持续录音，再短按一次结束。
- 按下即开始录音；按住超过 320ms 后松开即结束。若松开时服务仍在连接，结束意图必须保留到录音通道建立。
- 没有真实拖拽关闭行为时不显示拖拽把手，避免虚假交互暗示。

## 状态完整性

必须覆盖以下状态：空闲、权限请求、连接中、实时录音、文件录音回退、无转写、连接断开、解析中、确认、保存中和失败恢复。

- 连接、错误和解析文案只能占用预留槽位，不得挤动麦克风或关闭按钮。
- 关闭解析页后，迟到的解析或澄清结果不得重新写回界面。
- 保存请求开始后禁止关闭，直到成功或失败结果明确，避免用户退出后仍静默创建日程。
- 录音错误需要被 TalkBack 自动播报；按钮标签和忙碌状态必须随状态更新。

## 验收方法

自动化测试负责确定性合同：短按、长按拖选、空白取消、连接中松手、连续录音、布局常量、异步结果失效和保存不可关闭。

真机由使用者进行少量定向验收：单手长按加号是否容易命中两个目标；正常说话时首句是否丢失；短按与按住两种录音方式是否符合预期；系统字体放大后标题、关闭按钮和错误文案是否互不遮挡。

性能单独记录，不与视觉验收混在一起：按下到开始采集、按下到连接完成、首个转写片段、松开到结构化草稿四个时延分别测量。截图只用于定位明确的布局问题，不作为交互正确性的主要证据。

# LaoJi theme fonts

The four binaries in `theme/` are common-Chinese subsets with LaoJi-specific
internal family names. They are generated by
`tools/fonts/build_theme_font_subsets.py`; the pinned upstream revisions,
source hashes, output hashes and codepoint counts are recorded in
`theme/manifest.json`.

| Theme | UI source family | Internal family | License |
|---|---|---|---|
| 标准 | Noto Sans CJK SC | `LaojiThemeNeutral` | SIL OFL 1.1 |
| 绚彩 | ChillRoundF | `LaojiThemeVivid` | SIL OFL 1.1 |
| 纸境 | LXGW WenKai | `LaojiThemePaper` | SIL OFL 1.1 |
| 夜航 | LXGW Neo ZhiSong Screen | `LaojiThemeMidnight` | IPA Font License 1.0 |

The original family names remain product attribution only. They are not used
as the primary family names of the modified subset binaries. Licenses and
upstream notices are retained under `licenses/` and packaged with Android
release assets.
